# 🍱 食事カロリー記録 (Meal Calorie Tracker)

iPhoneのSafariからホーム画面に追加して使う、食事カロリー記録Webアプリ（PWA）。

## 機能

- 🌅☀️🌙🍬 **4つの食事区分**: 朝食 / 昼食 / 夕食 / おやつ
- 📊 **目標カロリー自動計算**: 体重・身長・年齢・性別・活動レベルから Mifflin-St Jeor 式で BMR/TDEE を算出
- 🎯 **差分表示**: 目標に対する達成度をプログレスバーと差分（あと/オーバー）で可視化
- 🍱 **食品アイコン**: 食品ごとに絵文字アイコン
- ➕ **食品マスター追加**: 後から自由に食品を追加・編集・削除
- ⭐ **お気に入り**: よく食べる食品にチェック → 食品追加モーダルで上に表示
- 📅 **日付ナビ**: 過去の日付に戻って入力・修正可能
- 📈 **履歴**: 記録のある日を一覧表示、タップで詳細へ
- 💾 **CSV エクスポート / JSON バックアップ**: Mac へのデータ移行・バックアップに対応
- 📱 **PWA 対応**: iPhone のホーム画面に追加すると全画面アプリのように起動

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | アプリ本体（HTML/CSS/JS、単一ファイル完結） |
| `manifest.json` | PWA マニフェスト |
| `起動.command` | Mac でローカル動作確認用 |
| `iPhoneセットアップ手順.md` | iPhone でのセットアップ手順書 |

## ストレージ

- データは**端末のブラウザ localStorage** に保存されます
- iPhone と Mac は別データ（自動同期なし）
- 端末間の移行は CSV / JSON エクスポート経由

## 計算式

- **基礎代謝 (BMR)**: Mifflin-St Jeor 式
  - 男性: `10 × 体重(kg) + 6.25 × 身長(cm) − 5 × 年齢 + 5`
  - 女性: `10 × 体重(kg) + 6.25 × 身長(cm) − 5 × 年齢 − 161`
- **推定消費 (TDEE)**: `BMR × 活動レベル係数 (1.2 〜 1.9)`
- **目標カロリー**: TDEE （または「目標カロリーの手動設定」で上書き）

## セットアップ

iPhone で使う場合は [`iPhoneセットアップ手順.md`](iPhoneセットアップ手順.md) を参照してください。
Mac で動作確認するだけなら `起動.command` をダブルクリックするだけです。
